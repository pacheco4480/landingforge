# Public Roadmap

This roadmap summarizes the public product direction for LandingForge.

It intentionally avoids private implementation notes and internal task planning.

## Completed Foundations

- Next.js application foundation
- Modular source structure
- Prisma/PostgreSQL schema
- CMS shell
- Authentication and RBAC
- Content management
- Forms engine
- Leads engine
- SEO management
- Branding and theme controls
- Media management foundation
- Monitoring/error logging foundation
- Public renderer
- Initial industry template foundations
- Real Estate demos
- Clinic demos
- Restaurant demos
- Public portfolio catalogue foundation with demo visibility controls

## Current Focus

- Reviewing and approving selected demos for public presentation
- Refreshing screenshots against the current implementation
- Improving visual differentiation between template variants
- Completing end-to-end acceptance of the commercial client workflows
- Preparing curated product and engineering showcases

## Implemented Locally; Release Acceptance in Progress

- Internal client/project workspace with structured briefing and review flows
- On-demand Landing Only and Landing + CMS package generation with package audits
- Managed maintenance, project rebase and delivery-documentation foundations
- Operational privacy request and retention-review workflows

These capabilities have local implementation and test evidence. This status does
not certify production deployment, every target host, provider-backed email, or
the complete release sign-off for every client workflow.

## Planned Template Industries

- Construction
- Beauty

Bakery and Gym foundations/selected variants exist; further variants and final demo approval remain separate work.

## Planned Product Improvements

- More template variants
- More polished media workflows
- More analytics and reporting capabilities
- More automated quality checks
- Final integrated acceptance and release sign-off for client provisioning,
  package export, maintenance and handover workflows
- Destination-specific deployment, cron, recovery and provider validation

The roadmap describes direction, not a delivery commitment. Client package
generation is implemented locally; one-click deployment across hosting
providers is not available or implied.

## Long-Term Direction

LandingForge is intended to become a reusable platform for delivering premium landing pages quickly while keeping engineering quality, performance and content management under control.
