# Template System

LandingForge templates are built around industry-specific foundations and curated visual variants.

The goal is to make each template feel like a real landing page for a real business, while still sharing reusable architecture.

## Template Principles

- Templates should be industry-specific.
- Variants should have distinct visual positioning.
- Content should be CMS-editable.
- Layouts should remain performant and accessible.
- Shared logic should be reused across templates.
- Visual quality should not depend on one-off hacks.

## Industry Foundations

An industry foundation can define:

- reusable section patterns;
- industry-specific utilities;
- theme defaults;
- demo content structure;
- SEO/schema defaults;
- common forms;
- template registration.

Examples:

- Real Estate
- Clinic
- Restaurant
- Bakery
- Gym
- Construction
- Beauty

## Template Variants

Variants provide different positioning within the same industry.

Examples:

- Real Estate Local Agency
- Real Estate Premium
- Clinic Modern
- Clinic Luxury
- Restaurant Fine Dining
- Restaurant Playful

Each variant should differ in:

- layout rhythm;
- photography direction;
- color palette;
- typography tone;
- CTA treatment;
- trust signals;
- storytelling;
- interaction style.

## CMS Editability

Templates should expose editable content without making layout quality fragile.

Common editable areas:

- hero copy;
- CTAs;
- images;
- service cards;
- testimonials;
- contact details;
- SEO metadata;
- form configuration.

## Public Rendering

The public renderer maps stored content to section components.

This keeps public pages:

- consistent;
- reusable;
- SEO-friendly;
- safer to operate;
- easier to extend.

## Portfolio Value

Each template can become a case study with:

- desktop and mobile screenshots;
- brand identity direction;
- UX flow;
- CMS-editable story;
- SEO/performance/accessibility notes.

Only implemented variants with a reviewed, explicitly published demo should appear as available in the public catalogue or showcase. Screenshots are snapshots and must be refreshed against the current demo before commercial use. Fictional demo brands and metrics must never be presented as real clients or measured outcomes.
